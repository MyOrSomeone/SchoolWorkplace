SPC Terminale — Thème 1 : Constitution & Transformations

I. Les Couples Acide / Base (Théorie de Brönsted)

Comprendre les échanges de protons $H^+$, les espèces conjuguées et le rôle amphotère de l'eau.

Donneur de proton

L'Acide (AH)

Espèce chimique capable de céder au moins un proton $H^+$ lors d'une réaction chimique.

$\text{Acide} \longrightarrow \text{Base conjuguée} + H^+$
Accepteur de proton

La Base ($A^-$)

Espèce chimique capable de capter au moins un proton $H^+$.

$\text{Base} + H^+ \longrightarrow \text{Acide conjugué}$
Demi-équation acido-basique & Couple Acide/Base

Un couple acide/base est noté $\text{Acide}/\text{Base}$ (ex : $\text{AH}/\text{A}^-$). Ils sont reliés par le schéma d'échange :

$$\text{Acide} \rightleftharpoons \text{Base} + H^+$$

Remarque : Le proton $H^+$ n'existe jamais à l'état libre dans l'eau ; il est toujours immédiatement capté par une autre espèce chimique (souvent l'eau elle-même).

Le cas remarquable de l'Eau ($H_2O$)

Une espèce amphotère (ou ampholyte)

L'eau peut se comporter **soit comme un acide, soit comme une base** selon l'espèce avec laquelle elle réagit. Une telle espèce est dite amphotère (ou un ampholyte).

1. L'eau agit comme BASE

Elle capte un proton $H^+$ pour devenir l'ion oxonium $H_3O^+$ :

$H_3O^+_{(aq)} / H_2O_{(l)}$
Demi-équation : $H_3O^+_{(aq)} \rightleftharpoons H_2O_{(l)} + H^+$
2. L'eau agit comme ACIDE

Elle cède un proton $H^+$ pour devenir l'ion hydroxyde $HO^-$ :

$H_2O_{(l)} / HO^-_{(aq)}$
Demi-équation : $H_2O_{(l)} \rightleftharpoons HO^-_{(aq)} + H^+$
