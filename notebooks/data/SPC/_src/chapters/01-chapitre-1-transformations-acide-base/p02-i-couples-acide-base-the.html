I — Théorie de Brönsted

Couples acide / base

Comprendre les échanges de protons H⁺, les espèces conjuguées et le rôle amphotère de l’eau.

1 — Définitions

Un acide

Espèce chimique susceptible de céder un ou plusieurs protons H+.

Une base

Espèce chimique susceptible de capter un ou plusieurs protons H+.

Couple acide/base

Un couple acide/base est constitué d’un acide et de sa base conjuguée, reliés par la demi-équation acido-basique :

\[ \text{AH} \rightleftharpoons \text{A}^- + \text{H}^+ \]
acide = base conjuguée + H⁺

2 — Réaction acido-basique

Définition

Une réaction acide-base est un échange de protons H+ entre l’acide d’un premier couple et la base d’un second couple. Ce sont le plus souvent des réactions rapides.

Laboratoire de transfert de protonsInteractif

Un acide cède un proton H⁺, une base le capte : fais-le toi-même, puis combine deux couples.

① Un couple, un proton

Choisis un couple puis fais céder ou capter un proton H⁺.

② Une réaction acido-basique

L’acide d’un couple 1 réagit avec la base d’un couple 2 : un proton passe de l’un à l’autre.

Les trois couples de l’eau et des solutions courantes se retrouvent dans le laboratoire ci-dessus : CH₃COOH / CH₃COO⁻ (acide éthanoïque), H₃O⁺ / H₂O (acide chlorhydrique dissous) et H₂O / HO⁻ (soude dissoute).

3 — Le cas de l’eau

L’eau est amphotère

L’eau est la forme acide du couple H2O(l) / HO−(aq). Elle est aussi la forme basique du couple H3O+(aq) / H2O(l). Une espèce chimique qui peut être un acide ou une base est appelée espèce amphotère.
